# Multi-Cloud Threat Detection

ML-driven framework for detecting anomalous activities across AWS, Azure, and Google Cloud.

## Features

- Multi-cloud security event analysis
- Machine learning anomaly detection
- Threat classification
- Risk scoring
- Cross-cloud event correlation
- Interactive security dashboard

## Tech Stack

Python, Pandas, NumPy, Scikit-learn, XGBoost, Streamlit, Plotly
